Modulo

Why modulo breaks

Every key's node depends on N. Change N from 4 to 5 and a key stays put only if h % 4 == h % 5, which is about 1 in 5. So roughly 80% of keys move, and a cache cluster loses most of its hits at once.

  • Fine when N never changes, or when you can afford a full rebalance.
  • Fixed slots fix it: hash into many slots (Redis Cluster uses 16,384) and move whole slots between nodes.

How the ring works

Hash nodes and keys onto the same circle. A key belongs to the first node clockwise from it. Adding a node takes over one stretch of the ring, so only about 1/N of keys move, and only to the new node.

  • With one point per node the stretches are uneven, so some nodes get several times their share.
  • Virtual nodes give each node many points, which evens out load and spreads a removed node's keys over all the others. Cassandra uses 16 tokens per node by default.
  • Alternatives: rendezvous hashing (highest score wins, no ring) and jump hash (no memory, but nodes can only be added or removed at the end).
